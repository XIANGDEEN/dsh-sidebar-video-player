# DSH 侧边栏视频播放器

[English](README.md) | 简体中文

一个运行在 DeepSeek Harness（`dsh`）**右侧栏**的视频播放器，带实时播放指标和一个只读的 MP4/MOV 容器解析器。

打开它，你可以在对话旁边播放本地视频，同时查看分辨率、精确帧数、平均帧率、每轨码率、编码档次/级别、缓冲状态和丢帧——这些数值是普通 `<video>` 元素不会直接暴露的。

## 安装

GitHub 源码安装（不需要 npm）：

```sh
dsh plugin --profile web add github:XIANGDEEN/dsh-sidebar-video-player
```

DSH 桌面客户端使用的 desktop profile：

```sh
dsh plugin --profile desktop add github:XIANGDEEN/dsh-sidebar-video-player
```

如果之后发布到 npm，也可以用包名安装：

```sh
dsh plugin --profile web add dsh-sidebar-video-player
```

安装后重启或刷新 Web UI。插件会以已启用的 bundle 行 `dsh-sidebar-video-player` 出现。

## 打开方式

- 右侧栏 → **开始**（Start 指南）→ **视频播放器**。
- 或点击左侧栏底部 Settings 旁的视频图标。

播放器是右侧栏里的一个标签页。右侧栏按会话隔离，所以需要先打开一个会话；没有会话时底部图标是禁用的。

## 功能

- 选择本地视频或拖拽播放，也可以加载 HTTP(S) 视频地址。
- **文件夹播放列表**：选择一个文件夹，其中所有视频会列在播放器右侧。每个卡片显示**首帧缩略图**和时长徽标；点击切换。当前项高亮，播放结束后自动下一个。
- **排序**：按名称、时长、修改时间或大小排序，支持升序/降序。
- 自定义控制条：播放/暂停、拖动进度、音量、静音、倍速、画中画、全屏。
- 播放器有焦点时的键盘快捷键：`Space` / `K`、`J` / `L`、方向键、`M`、`F`。
- 实时播放指标：
  - 当前时间、总时长、进度、已缓冲区间和缓冲余量；
  - 通过 `requestVideoFrameCallback` 实测的解码帧率；
  - 通过 `getVideoPlaybackQuality()` 获取的已呈现帧、丢帧和总视频帧；
  - 播放速率和播放器状态（播放中、暂停、缓冲中、已结束）。
- 不依赖解码的 MP4/MOV 深度解析：
  - 容器：主品牌/兼容品牌、timescale、时长、`moov` 位置、是否分片、轨道数；
  - 视频：编码 fourcc、H.264/HEVC 档次和级别、编码/显示尺寸、宽高比、旋转、精确帧数、平均帧率、每轨码率、位深、时长；
  - 音频：编码、AAC 档次、采样率、声道数、码率、时长。
- 其他浏览器可解码的容器（WebM、Ogg 等）仍可播放，并显示实测分辨率、帧率和帧计数；容器级解析只覆盖 MP4/MOV。
- 可折叠的**原始解析数据**面板显示精确的解析 JSON。
- 中英文文案，使用宿主主题 token。

## MP4/MOV 读取原理

读取器不会把整个文件读进内存。它用 `Blob.slice` 遍历顶层 ISO-BMFF 盒子，只读一次 `moov`（上限 64 MiB），提取：

- `mvhd`：影片 timescale/时长；
- 每个 `trak` → `tkhd`（显示尺寸、旋转）、`mdhd`（轨道 timescale/时长、语言）、`hdlr`（视频/音频 handler）、`stsd`（样本条目、编码 fourcc、`avcC`/`hvcC`/`av1C`、`esds`）、`stts`（样本数和时序）、`stsz`（样本字节数，用于每轨码率）。

报告的是整条轨道的平均值，不是瞬时码率。检测分片 MP4；样本表为空时，播放器回退到 `<video>` 元素的实测指标。

## 兼容性

- 需要 DSH `>=0.2.1-rc.3 <0.3.0-0`；面向 Web 客户端构建和测试。
- 需要浏览器能解码所选容器/编码。MP4/H.264/AAC 最稳妥；HEVC/AV1 取决于浏览器。
- 播放器是纯视图层：不注册智能体工具，不写入会话事件，不向 Host 请求文件系统权限。

## 权限与隐私

- 选中的本地文件通过浏览器 Blob URL 读取，不会上传。
- 网络地址只由浏览器为了播放而请求；插件不代理远程媒体，也不读取远程容器元数据。
- 不使用分析、遥测、外部服务或凭据。
- 唯一的 Host 侧表面是插件 bundle 行；所有播放器状态都留在 Web 页面内。

| 文件 | 分辨率 | 帧数 | 平均帧率 | 视频码率 | 音频 |

| `boot.mp4` | 1280 × 720 | 193 | 24.000 | 2.50 Mbps | AAC LC，32 kHz，立体声 |
| `background.mp4` | 1600 × 914 | 3766 | 30.000 | 0.68 Mbps | 无 |

这些值与同文件的 `ffprobe` 流元数据一致。插件在源码仓库中还通过了模块工厂、manifest/locale/patch 和注册契约检查。

## 已知限制

- 深度容器解析覆盖 `.mp4`、`.m4v`、`.mov`；其他格式可以播放，但只能拿到浏览器报告的指标。
- 网络视频不做容器探测（不假设跨域读取可用）。
- 加密样本条目（`encv`/`enca`）不解密、不解析。
- 每轨码率是整条轨道的平均码率，不是实时网络码率。
- 右侧栏按会话隔离；没有打开的会话就没有播放器。
